# FLL Mission Planner

A click-to-plan mission strategy tool for the FIRST LEGO League Challenge field.

**How students use it**
1. Enter a team name and run (optional; these are printed on the downloaded image).
2. Click the red or blue launch area and confirm it as the starting point.
3. Click each mission in the order the robot will do it and pick the planned points.
   For a white box, first choose Mission 13, 14 or 15, then pick the points.
4. Click a launch area to plan a return. Blue lines = to a mission; red lines = to a launch area.
5. Click **Calculate** to see the total (it includes the starting 90 points) and download the plan as a PNG.

**Hosting on GitHub Pages**
1. Create a new public repository and upload `index.html` and `map.jpg` to the main branch.
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", and pick `main` / `(root)`.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

Note: the image download only works when the page is opened from a web address (GitHub Pages), not by double-clicking the file on your computer.
